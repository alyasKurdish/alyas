# ZERO PHONE — سیستەمی فرۆشتن (POS) — وەشانی Turso + Cloudflare

سیستەمێکی فرۆشتنی کوردی بۆ دووکانی ئەکسسواری مۆبایل. **بێ پارە**، بێ سێرڤەری تایبەت. سێ بەش هەیە:

| بەش | چییە | کوێیە |
|---|---|---|
| **ڕووکار** | ئەم repository یە (HTML + JS) | **GitHub Pages** |
| **سێرڤەر** | `worker/worker.js` — هەموو لۆجیکی فرۆشتن، کۆگا، قازانج، چوونەژوورەوە | **Cloudflare Worker** (پلانی خۆڕایی) |
| **داتابەیس** | هەموو داتاکان (کاڵا، فرۆشتن، بەکارهێنەر...) | **Turso** (پلانی خۆڕایی) |

> ئەم وەشانە هەمان ڕووکار و هەمان لۆجیکی وەشانی Supabase ە؛ تەنها سێرڤەر و داتابەیسەکەی گۆڕاوە. فۆڵدەری `sql/` هی وەشانە کۆنەکەیە و لێرە بەکارنایەت (تەنها بۆ سەیرکردنە).

## چی دەکات؟

- **دوو ڕۆڵ**: ئادمین (هەموو شتێک) و کاشێر (تەنها فرۆشتن و گەڕاندنەوە). هەرکەسە بە ناو و وشەی نهێنی خۆی دەچێتە ژوورەوە.
- **کاشێر**: شاشەی فرۆشتن، سکانی بارکۆد، داشکان (تا سنوورێک ئادمین دایدەنێت)، چاپی وەسڵ (٨٠مم)، گەڕاندنەوە. هیچ کاڵایەک دەستکاری ناکات و تێچوو/قازانج نابینێت.
- **ئادمین**: داشبۆرد، کاڵاکان، هێنانی کاڵا (مەخزەن)، وەسڵەکان لەگەڵ تێچوو و قازانج، ڕاپۆرتەکان، **ڕاپۆرتی نەفرۆشراو**، بەکارهێنەران، ڕێکخستنەکان، ئێکسپۆرتی CSV.
- **دینار بێ دەیگە** (IQD). فرۆشتن بە دانە؛ هەر هێنانێکی کاڵا بە **کۆی نرخی کڕین** تۆمار دەکرێت.
- **قازانج لە کاتی فرۆشتنەکەدا** دیاری دەکرێت (تێچووی ناوەندی کێشراو)، بۆیە گۆڕینی نرخی دواتر قازانجی کۆن ناگۆڕێت.
- لەسەر کۆمپیوتەر و مۆبایل کار دەکات، و وەک ئەپ دادەبەزێت (PWA).

## خزمەتگوزارییەکان (چاکردنەوە و کارت)
- لە مێنیوی **خزمەتگوزاری** (کاشێر و ئادمین): **چاکردنەوە** و **کارت**. تەنها **قازانجی دووکان** تۆمار دەکرێت (وەک ٥٬٠٠٠ یان ٣٥٠)، نەک نرخی پارچە یان کارتەکە. هەر کڕیارێک تۆمارێکی جیاوازە. بۆ کارت دوگمەی خێرای ٣٥٠ و ٤٥٠ هەیە.
- کاشێر تەنها تۆمارەکانی ئەمڕۆی خۆی دەبینێت و ناتوانێت دەستکاری یان هەڵیانوەشێنێتەوە.
- ئادمین هەموو ماوەکان، فلتەر بەپێی جۆر/کاشێر، هەڵوەشاندنەوە و CSV هەیە. لە **داشبۆرد** و **ڕاپۆرتەکان ← خزمەتگوزاری** قازانجی کاڵا / چاکردنەوە / کارت و کۆی گشتی جیا دەبینرێت.
- خزمەتگوزارییەکان **ناچنە ناو کۆی فرۆشتن** — تەنها قازانج.

## دامەزراندن — هەنگاو بە هەنگاو (یەک جار)

### ١) داتابەیس لە Turso
1. [app.turso.tech](https://app.turso.tech) ← **Create Database** ← ناو: `pos` ← ناوچەی نزیک (نموونە: Stockholm).
2. لە لاپەڕەی داتابەیسەکە (**Overview**) دوو شت پێویستە:
   - **Database URL** — شتێکی وەک `libsql://pos-ناوی-تۆ.aws-eu-north-1.turso.io`
   - **Create Token** ← **Read & Write** ← بێ ماوە (never expires) ← تۆکنەکە کۆپی بکە (تەنها یەک جار نیشان دەدرێت!).
3. هیچ خشتەیەک دروست مەکە؛ Worker خۆی لە یەکەم داواکاریدا هەموو خشتەکان دروست دەکات.

### ٢) سێرڤەر لە Cloudflare
1. هەژمارێکی خۆڕایی لە [dash.cloudflare.com](https://dash.cloudflare.com) دروست بکە.
2. **Workers & Pages** ← **Create** ← **Worker** (Hello World) ← ناو: `zp-pos` ← **Deploy**.
3. **Edit code** ← هەموو کۆدی نمونەکە بسڕەوە ← ناوەڕۆکی [`worker/worker.js`](worker/worker.js) هەمووی لێ بنووسە (Paste) ← **Deploy**.
4. **Settings ← Variables and Secrets** ← دوو شت زیاد بکە:
   - `TURSO_URL` — جۆر: **Text** — **Database URL** ی Turso
   - `TURSO_TOKEN` — جۆر: **Secret** — تۆکنی Turso
   پاشان **Deploy** بکە.
5. **Settings ← Runtime ← Placement ← Smart** (Worker لە نزیک داتابەیسەوە کار دەکات و خێراتر دەبێت).
6. ناونیشانی Worker (`https://zp-pos.ناوی-تۆ.workers.dev`) بکەرەوە و `/health` ی بخەرە سەری؛ دەبێت `{"ok":true}` ببینیت.

### ٣) `config.js` دەستکاری بکە
```js
API_URL: 'https://zp-pos.ناوی-تۆ.workers.dev',   // ناونیشانی Worker
USERNAME_DOMAIN: 'shop.krd',                      // وەک خۆی بهێڵەوە
```
- ناوی بەکارهێنەر (وەک `sara`) لە ژێرەوە دەبێتە `sara@shop.krd`. هیچ نامەیەک ناڕەوانە دەکرێت.
- **دوای دروستکردنی یەکەم هەژمار `USERNAME_DOMAIN` مەگۆڕە.**
- لەبری ئەمە دەتوانیت `LOGIN_EMAIL: 'you@gmail.com'` بەکاربهێنیت (ناوەکان دەبن بە `you+sara@gmail.com`).

### ٤) GitHub Pages
**Settings ← Pages ← Deploy from a branch ← main / (root) ← Save.** ناونیشان: `https://USER.github.io/REPO/`

### ٥) یەکەم ئادمین — **بەر لە بڵاوکردنەوەی لینکەکە!**
لینکەکە بکەرەوە؛ شاشەی «دامەزراندن» دەردەکەوێت. یەکەم کەسێک هەژمار دروست بکات **دەبێتە ئادمین**. هەر ئێستا ئەمە بکە، پێش ئەوەی لینکەکە بدەیت بە کەس.
پاشان: **ڕێکخستنەکان** (ناوی دووکان، سنووری داشکان، ماوەی گەڕاندنەوە) ← **بەکارهێنەران** (کاشێر زیاد بکە) ← **کاڵاکان** (کاڵا زیاد بکە).

## نوێکردنەوەی سێرڤەر
ئەگەر `worker/worker.js` گۆڕدرا: Cloudflare ← Workers & Pages ← `zp-pos` ← **Edit code** ← کۆدی نوێ لە جیاتی کۆنەکە ← **Deploy**. داتاکان ناگۆڕێن؛ خشتەکان خۆیان نوێ دەبنەوە ئەگەر پێویست بێت.

## قازانج چۆن حیساب دەکرێت؟

تێچووی ناوەندی کێشراو. نموونە:
- ١٠ دانە بە کۆی ٣٠٬٠٠٠ ← ١٠ دانە، بەهای ٣٠٬٠٠٠
- ٥ دانە بە کۆی ٢٠٬٠٠٠ ← ١٥ دانە، بەهای ٥٠٬٠٠٠ (ناوەند ≈ ٣٬٣٣٣ بۆ هەر دانەیەک)
- فرۆشتنی ٢ دانە بە ١٠٬٠٠٠ ← تێچوو ≈ ٦٬٦٦٧، قازانج ≈ ٣٬٣٣٣

داشکانی وەسڵ بەسەر دانەکاندا دابەش دەکرێت و کۆکەی تەواو دەگاتەوە.

## گەڕاندنەوە
- کاشێر لە ماوەی ڕێگەپێدراودا (ڕێکخستنەکان) دەتوانێت گەڕاندنەوە بکات؛ ئادمین هەمیشە.
- **گەڕاندنەوە بۆ مەخزەن**: کاڵا دەگەڕێتەوە ستۆک و تێچووەکەی دەگەڕێتەوە.
- **بێ گەڕاندن بۆ مەخزەن** (تێکچوو): پارە دەگەڕێتەوە، بەڵام تێچووەکە وەک زیان دەمێنێتەوە.
- ناتوانرێت زیاتر لە ماوەی فرۆشراو بگەڕێنرێتەوە.

## بارکۆد و چاپ
- سکانەری بارکۆد وەک کیبۆرد کار دەکات: کلیک لە خانەی گەڕان بکە و سکان بکە.
- وەسڵ بۆ چاپگەری ٨٠مم ئامادەیە. بۆ چاپی خێرا بێ پرسیار، Chrome بە `--kiosk-printing` بکەرەوە.

## پشتیوانی (Backup)
- **Turso ← pos ← Overview ← Export Database ← «Download SQLite File»** — هەموو داتاکانت لە یەک فایلدا دەگرێت. هەفتانە یان مانگانە ئەمە بکە و فایلەکە لە شوێنێکی تر هەڵبگرە.
- لە ناو سیستەمەکەش **ئێکسپۆرتی CSV** لە وەسڵەکان، کاڵاکان و ڕاپۆرتەکان هەیە.
- **سڕینەوەی داتای تاقیکردنەوە** پێش دەستپێکردنی ڕاستەقینە: Turso ← pos ← **Edit Data** (یان SQL console) ← ئەم فەرمانانە بەو ڕیزەیە:
  ```sql
  delete from sale_returns; delete from sale_items; delete from sales;
  delete from service_entries; delete from stock_movements; delete from purchases; delete from products;
  ```
  (بەکارهێنەرەکان و ڕێکخستنەکان دەمێنن.)

## بیرچوونەوەی وشەی نهێنی ئادمین
ئەگەر تاکە ئادمینەکە وشەی نهێنی لەبیر کرد:
1. لە لاپەڕەی چوونەژوورەوە هەژمارێکی نوێ دروست بکە (نموونە `temp`) بە وشەی نهێنییەکی نوێ کە دەیزانیت.
2. لە Turso ← pos ← **Edit Data** / SQL console ئەمە بکە (ناوی ئادمینەکە بنووسە لە جیاتی `ADMIN-NAME`):
   ```sql
   update profiles set pw_hash = (select pw_hash from profiles where username = 'temp') where username = 'ADMIN-NAME';
   delete from sessions;
   ```
3. بە ناوی ئادمین و وشەی نهێنی `temp` بچۆ ژوورەوە، لە **هەژمارەکەم** (ناوەکەت لای چەپی خوارەوە) وشەی نهێنی بگۆڕە، پاشان بەکارهێنەری `temp` بسڕەوە.

## کێشەکان

| پەیام / نیشانە | چارەسەر |
|---|---|
| «پەیوەندی بە سێرڤەر ڕێکنەخراوە» | `config.js` ← `API_URL` ناونیشانی ڕاستەقینەی Worker بنووسە. |
| «سێرڤەرەکە ڕێکنەخراوە» (`SERVER_NOT_CONFIGURED`) | Cloudflare ← Worker ← Settings ← Variables: `TURSO_URL` و `TURSO_TOKEN` دابنێ و Deploy بکە. |
| «سێرڤەر نەیتوانی بگاتە داتابەیس» (`DB_ERROR`) | تۆکنی Turso هەڵەیە/بەسەرچووە، یان `TURSO_URL` هەڵەیە. تۆکنێکی نوێ دروست بکە و لە Cloudflare بیگۆڕە. |
| `/health` وەڵامی `{"ok":true}` نادات | کۆدی Worker تەواو Paste نەکراوە یان Deploy نەکراوە. |
| `Error 1102` / «exceeded resource limits» | Worker لە پلانی خۆڕایی کاتی CPU ی تەواو بوو. زۆر کەمە ڕوودەدات؛ دووبارە هەوڵبدەرەوە. ئەگەر بەردەوام بوو، Cloudflare ← Workers Paid ($5/مانگ). |
| «هەژمارەکەت چالاک نییە» | ئادمین لە بەکارهێنەران پەسەندی بکات. |
| لاپەڕەکە نوێ نابێتەوە | Ctrl+F5؛ دوای گۆڕینی فایلەکان GitHub Pages چەند خولەک دەخایەنێت. |

## سنووری پلانە خۆڕاییەکان
- **Cloudflare Workers**: ١٠٠٬٠٠٠ داواکاری لە ڕۆژێکدا (بۆ دووکانێک زۆر زیاترە لە پێویست) و ~١٠ میلی چرکە CPU بۆ هەر داواکارییەک.
- **Turso**: سنووری پلانی خۆڕایی (قەبارە، ژمارەی خوێندنەوە و نووسین لە مانگێکدا) لە Turso ← Usage / Billing دەبینرێت؛ بۆ POS ی دووکانێک بەشە.

## بۆ گەشەپێدەر
- بێ build و بێ کتێبخانە: HTML + ES modules. فایلەکان: `js/pages/*` (لاپەڕەکان)، `js/api.js` (پەیوەندی)، `js/i18n.js` (هەڵە کوردییەکان)، `css/*`.
- `worker/worker.js` — یەک فایلی ES module (~١٤٠٠ دێڕ): خشتەکانی SQLite (خۆکار)، کڕینی وشەی نهێنی (PBKDF2)، تۆکنی HMAC، هەموو فەنکشنەکان (RPC) بە هەمان ناو و فۆرماتی وەشانی Supabase. کلاینتی داتابەیس: Hrana over HTTP بۆ `TURSO_URL`.
- پارە و کات: دیناری تەواو؛ کات وەک ISO-UTC هەڵدەگیرێت و ڕۆژ بە کاتی بەغدا (UTC+3) دیاری دەکرێت.
- هەموو گۆڕانکارییەک لە فرۆشتن/کۆگا لە یەک transaction دایە (`begin immediate`)، و `client_id` ی هەر داواکارییەک نایەڵێت دووبارە تۆمار بکرێت.
- متغیرە ئارەزووەکان: `PBKDF2_ITER` (١٠٠٠–١٠٠٠٠٠، بنەڕەت ٢٠٠٠٠)، `ACCESS_TTL` (چرکە، بنەڕەت ٣٦٠٠)، `JWT_SECRET` (ئەگەر نەبێت `TURSO_TOKEN` بەکاردێت).

## چی تاقی کرایەوە و چی نا

**تاقیکرایەوە** (لە ناوخۆ: Worker + SQLite + شبیهکەری Turso (Hrana) + Chromium بێ سەر):
- ١٢٧ هەنگاوی بەراوردکردن لەگەڵ وەشانی Postgres: هەمان داواکاری ← هەمان وەڵام بە وردی (کاڵا، کۆگا، فرۆشتن، داشکان، گەڕاندنەوە، ڕاپۆرت، خزمەتگوزاری، بەکارهێنەر، هەڵەکان).
- ٤٤ سیناریۆی وێبگەڕ (فرۆشتن، گەڕاندنەوە، ڕاپۆرتەکان، چوونەژوورەوە، نوێکردنەوەی تۆکن، مۆبایل).
- فرۆشتنی هاوکات (٢٤ فرۆشتن لە یەک کاتدا بۆ ٥ دانە ← تەنها ٥ سەردەکەون، ستۆک هەرگیز نابێتە سالب)؛ داواکاری دووبارە تەنها یەک جار تۆمار دەبێت.
- کاتی CPU ی هەر داواکارییەک (زۆربەی ١–٥ میلی چرکە).

**تاقی نەکرایەوە** تا ئێستا: Turso و Cloudflare ی ڕاستەقینە (دوای دامەزراندن تاقی دەکرێتەوە)، Google Fonts، چاپگەری ڕاستەقینە. بۆیە **ڕۆژی یەکەم بە ئاگاوە بە**:
