# ZERO PHONE 2 — سیستەمی فرۆشتن (POS)

سیستەمێکی فرۆشتنی کوردی بۆ دووکانی ئەکسسواری مۆبایل. **بێ پارە**، بێ سێرڤەری تایبەت:
ڕووکارەکەی لەسەر **GitHub Pages** دەوەستێت و داتاکان لە **Supabase** (پلانی خۆڕایی) هەڵدەگیرێن.

## چی دەکات؟

- **دوو ڕۆڵ**: ئادمین (هەموو شتێک) و کاشێر (تەنها فرۆشتن و گەڕاندنەوە). هەرکەسە بە ناو و وشەی نهێنی خۆی دەچێتە ژوورەوە.
- **کاشێر**: شاشەی فرۆشتن، سکانی بارکۆد، داشکان (تا سنوورێک ئادمین دایدەنێت)، چاپی وەسڵ (٨٠مم)، گەڕاندنەوە. هیچ کاڵایەک دەستکاری ناکات و تێچوو/قازانج نابینێت.
- **ئادمین**: داشبۆرد، کاڵاکان، هێنانی کاڵا (مەخزەن)، وەسڵەکان لەگەڵ تێچوو و قازانج، ڕاپۆرتەکان، **ڕاپۆرتی نەفرۆشراو**، بەکارهێنەران، ڕێکخستنەکان، ئێکسپۆرتی CSV.
- **دینار بێ دەیگە** (IQD). فرۆشتن بە دانە؛ هەر هێنانێکی کاڵا بە **کۆی نرخی کڕین** تۆمار دەکرێت.
- **قازانج لە کاتی فرۆشتنەکەدا** دیاری دەکرێت (تێچووی ناوەندی کێشراو)، بۆیە گۆڕینی نرخی دواتر قازانجی کۆن ناگۆڕێت.
- لەسەر کۆمپیوتەر و مۆبایل کار دەکات.

## پێویستی

1. هەژمارێکی خۆڕایی [Supabase](https://supabase.com)
2. هەژمارێکی خۆڕایی [GitHub](https://github.com)
3. ئیمەیڵێکی ڕاستی تایبەت بە دووکان (Gmail باشە)

## دامەزراندن — هەنگاو بە هەنگاو

### ١) پڕۆژەی Supabase دروست بکە
New project ← ناوێک و وشەی نهێنی داتابەیس دابنێ ← نزیکترین ناوچە هەڵبژێرە ← چاوەڕێ بکە تا ئامادە دەبێت.

### ٢) داتابەیس دروست بکە
**SQL Editor** ← New query ← ناوەڕۆکی `sql/schema.sql` هەمووی کۆپی بکە ← **Run**. دەبێت «Success» ببینیت. (دووبارە Run کردنی بێ زیانە.)

### ٣) ڕێکخستنی چوونەژوورەوە
**Authentication** ← **Sign In / Providers** ← **Email**:
- **Confirm email** بکوژێنەوە (OFF) — ئەگەر نا، چوونەژوورەوە کار ناکات.
- Sign-ups با چالاک بن (ئەمە پێویستە بۆ دروستکردنی یەکەم ئادمین).

### ٤) کلیلەکان وەربگرە
**Project Settings ← API**: `Project URL` و کلیلی **publishable** (یان `anon` ی کۆن). **هەرگیز** `secret` یان `service_role` بەکار مەهێنە.

### ٥) `config.js` دەستکاری بکە
```js
SUPABASE_URL: 'https://xxxx.supabase.co',
SUPABASE_ANON_KEY: 'کلیلی publishable',
LOGIN_EMAIL: 'zerophone.shop@gmail.com',   // ئیمەیڵێکی ڕاستی تایبەت
```
- ناوی بەکارهێنەر (وەک `sara`) لە ژێرەوە دەبێتە `zerophone.shop+sara@gmail.com`. هیچ ئیمەیڵێک ناڕەوانە دەکرێت.
- Supabase ئیمەیڵی ساختە (example.com...) ڕەت دەکاتەوە، بۆیە ئیمەیڵی ڕاستی پێویستە.
- **دوای دروستکردنی یەکەم هەژمار `LOGIN_EMAIL` مەگۆڕە.**
- ئەگەر دۆمەینی خۆت هەیە، دەتوانیت `USERNAME_DOMAIN: 'myshop.com'` بەکاربهێنیت لە جیاتی `LOGIN_EMAIL`.
- ئەم فایلە لە GitHub دەبینرێت؛ کلیلی publishable ئاسایە بۆ ئەوە، بەڵام ئیمەیڵەکە بینراو دەبێت.

### ٦) بیخەرە سەر GitHub Pages
1. repository ی نوێ دروست بکە (**Public**).
2. هەموو فایلەکان بارکە (`index.html`، `config.js`، `css/`، `js/`، `sql/`، `.nojekyll`).
3. **Settings ← Pages ← Deploy from a branch ← main / (root) ← Save.**
4. چاوەڕێ بکە (تا ~١٠ خولەک). ناونیشان: `https://USER.github.io/REPO/`

### ٧) یەکەم ئادمین — **بەر لە بڵاوکردنەوەی لینکەکە!**
لینکەکە بکەرەوە؛ شاشەی «دامەزراندن» دەردەکەوێت. یەکەم کەسێک هەژمار دروست بکات **دەبێتە ئادمین**. هەر ئێستا ئەمە بکە، پێش ئەوەی لینکەکە بدەیت بە کەس.
پاشان: **ڕێکخستنەکان** (ناوی دووکان، سنووری داشکان، ماوەی گەڕاندنەوە) ← **بەکارهێنەران** (کاشێر زیاد بکە) ← **کاڵاکان** (کاڵا زیاد بکە).

## قازانج چۆن حیساب دەکرێت؟

تێچووی ناوەندی کێشراو. نموونە:
- ١٠ دانە بە کۆی ٣٠٬٠٠٠ ← ١٠ دانە، بەهای ٣٠٬٠٠٠
- ٥ دانە بە کۆی ٢٠٬٠٠٠ ← ١٥ دانە، بەهای ٥٠٬٠٠٠ (ناوەند ≈ ٣٬٣٣٣ بۆ هەر دانەیەک)
- فرۆشتنی ٢ دانە بە ١٠٬٠٠٠ ← تێچوو ≈ ٦٬٦٦٧، قازانج ≈ ٣٬٣٣٣

داشکانی وەسڵ بەسەر دانەکاندا دابەش دەکرێت و کۆکەی تەواو دەگاتەوە.

## گەڕاندنەوە
- کاشێر لە ماوەی ڕێگەپێدراودا (ڕێکخستنەکان) دەتوانێت گەڕاندنەوە بکات؛ ئادمین هەمیشە.
- **گەڕاندنەوە بۆ مەخزەن**: کاڵا دەگەڕێتەوە ستۆک و تێچووەکەی دەگەڕێتەوە.
- **بێ گەڕاندن بۆ مەخزەن** (تێکچوو): پارە دەگەڕێتەوە، بەڵام تێچووەکە وەک زیان دەمێنێتەوە.
- ناتوانرێت زیاتر لە ماوەی فرۆشراو بگەڕێنرێتەوە.

## بارکۆد و چاپ
- سکانەری بارکۆد وەک کیبۆرد کار دەکات: کلیک لە خانەی گەڕان بکە و سکان بکە.
- وەسڵ بۆ چاپگەری ٨٠مم ئامادەیە. بۆ چاپی خێرا بێ پرسیار، Chrome بە `--kiosk-printing` بکەرەوە.

## پشتیوانی (Backup)
- پلانی خۆڕایی Supabase پشتیوانی داگرتنی نییە. بەردەوام **ئێکسپۆرتی CSV** لە وەسڵەکان، کاڵاکان و ڕاپۆرتەکان بکە.
- پڕۆژەی خۆڕایی ئەگەر ماوەیەکی زۆر (~یەک هەفتە) بەکارنەهێنرێت ڕەنگە ڕابگیرێت؛ لە Supabase دووبارە چالاکی بکەرەوە. (لە بەڵگەنامەی Supabase دڵنیابە، ڕەنگە گۆڕابێت.)
- **سڕینەوەی داتای تاقیکردنەوە** پێش دەستپێکردنی ڕاستەقینە: `sql/reset_data.sql` لە SQL Editor ڕابکێشە (کاڵا و فرۆشتنەکان دەسڕێتەوە؛ بەکارهێنەرەکان دەمێنن).

## بیرچوونەوەی وشەی نهێنی ئادمین
لە SQL Editor (ئیمەیڵەکە بگۆڕە بۆ ئیمەیڵی ئادمینەکەت):
```sql
update auth.users
set encrypted_password = extensions.crypt('وشەی-نوێ', extensions.gen_salt('bf'))
where email = 'zerophone.shop+admin@gmail.com';
```

## کێشەکان

| پەیام / نیشانە | چارەسەر |
|---|---|
| «ڕێکخستن تەواو نییە» | `config.js` پڕ بکەرەوە (URL، کلیل، LOGIN_EMAIL). |
| `PGRST202` / فەنکشن نەدۆزرایەوە | `sql/schema.sql` ڕانەکراوە یان هەڵەی تێدا بوو؛ دووبارە Run بکە. |
| پێویستە ئیمەیڵ پشتڕاست بکرێتەوە | Authentication ← Email ← Confirm email بکوژێنەوە. |
| ئیمەیڵ نادروستە | `LOGIN_EMAIL` ئیمەیڵێکی ڕاستی بێت، نەک example.com. |
| تۆمارکردن ڕێگەپێنەدراوە | Sign-ups چالاک بکە. |
| «هەژمارەکەت چالاک نییە» | ئادمین لە بەکارهێنەران پەسەندی بکات. |
| لاپەڕەکە نۆێ نابێتەوە | Ctrl+F5؛ دوای گۆڕینی فایلەکان GitHub Pages چەند خولەک دەخایەنێت. |

## بۆ گەشەپێدەر
- بێ build و بێ کتێبخانە: HTML + ES modules. فایلەکان: `js/pages/*` (لاپەڕەکان)، `js/api.js` (پەیوەندی)، `js/i18n.js` (هەڵە کوردییەکان)، `css/*`.
- هەموو لۆجیکی داتا لە `sql/schema.sql` ە (فەنکشنی SECURITY DEFINER؛ RLS چالاکە و تەنها RPC بەکاردێت). کلاینت تەنها فەنکشن بانگ دەکات.

## چی تاقی کرایەوە و چی نا

**تاقیکرایەوە** (Postgres 16 ی ناوخۆیی + شبیهکەری Supabase + Chromium بێ سەر):
- ٥١٨ پشکنینی SQL (تێچوو، قازانج، داشکان، گەڕاندنەوە، ڕۆڵەکان، idempotency).
- ٣٨ سیناریۆی وێبگەڕ (فرۆشتن، گەڕاندنەوە، ڕاپۆرتەکان، چوونەژوورەوە، نوێکردنەوەی تۆکن، مۆبایل).
- چاپی ٨٠مم (PDF)، سکانی بارکۆد، کیبۆرد/فۆکەس.

**تاقی نەکرایەوە**: Supabase Auth ی ڕاستەقینە، trigger لەسەر `auth.users` ی ڕاستەقینە، `admin_set_password` (pgcrypto) لەسەر Supabase، هێدەرەکانی کلیلی publishable، Google Fonts، چاپگەری ڕاستەقینە. بۆیە **ڕۆژی یەکەم بە ئاگاوە بە**:

- [ ] ئادمین قازانجی وەسڵەکەی بینی، کاشێر نەیبینی
